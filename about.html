What is Matrix?

Matrix is a self-contained, static knowledge base for cloud engineering, DevOps, architecture, and AI/ML operations. It requires no backend, no database, and no API keys for core functionality.

Every piece of information lives in your browser. The site works offline after the first load and can be hosted on any static file server — GitHub Pages, Netlify, Vercel, S3, or even a Raspberry Pi.

The design philosophy is simple: no spoon, only infrastructure. No fluff. No clickbait. Just the commands, issues, use cases, and references you need to build and operate cloud systems.

How to Use

Mind Map — Browse 11 categories of cloud knowledge. Click any category header to expand it. Click a node card to open its detailed modal with overview, common issues, commands, use cases, and references.

Architecture Builder — Select components from the palette to auto-generate Mermaid diagrams and Terraform skeletons. Use the pattern library for pre-built architecture templates. Copy C4 model templates for documentation.

Search Hub — Search GitHub repositories and StackOverflow questions simultaneously. Quick tags provide one-click searches for common topics. Search history is saved locally in your browser.

Blog & Tech — Resources for technical writing, blogging platforms, open source contribution, and developer tooling recommendations.

Deploy Your Own

Want to fork this and customize it? The entire site is just 5 HTML files. No build process. No dependencies to install.

# 1. Create a new repo on GitHub # 2. Upload all 5 HTML files # 3. Enable GitHub Pages in Settings # 4. Done. Your site is live. # Or clone and push: git clone https://github.com/YOURNAME/matrix-kb.git cd matrix-kb # Edit files, then: git add . git commit -m "Custom Matrix build" git push origin main

All data is embedded in the HTML. To add new nodes, edit the categories array in index.html. To change colors, modify the CSS variables at the top of each file.
